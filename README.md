# Hola, soy Mario Meléndez 👋

Estudiante de **Ingeniería en Informática** en Duoc UC (Chile). Me interesa el desarrollo full stack: construyo APIs, apps móviles y sitios web para pequeñas y medianas empresas bajo **MM Digital Solutions**.

## Stack

- **Backend:** Java, Spring Boot, Spring Security, JPA, Flyway, microservicios
- **Frontend:** TypeScript, React, Vite, Tailwind CSS
- **CMS y e-commerce:** WordPress, WooCommerce
- **Móvil:** Kotlin, Jetpack Compose, Room
- **Datos:** PostgreSQL, MongoDB, Oracle, SQL
- **Nube y herramientas:** AWS (Cognito, EC2, API Gateway), Docker, GitHub Actions, Vercel, Git
- **Otros:** Python
- **Metodologías ágiles:** Scrum, Kanban, sprints, historias de usuario, backlog y roadmap; trabajo con Git, ramas y pull requests
